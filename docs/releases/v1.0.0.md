# Peach Robot v1.0.0

发布日期：2026-11-07。发布方式：本地完整交付包。稳定范围为 Ubuntu 24.04 amd64、ROS 2 Jazzy、Python 3.12、CPU 的 mock / 冻结 RGB-D 链路；这是工作区版本，各 ROS 包与共享 SDK 保留自己的版本号。

## 使用

发布目录提供 `peach_robot-v1.0.0.tar.zst`、同名 SHA-256、逐文件清单、发布说明和 `ACCEPTANCE.json`。先核对压缩包，再解压至英文无空格路径；工作区内容在 `peach_robot-v1.0.0/`：

```bash
sha256sum -c peach_robot-v1.0.0.tar.zst.sha256
tar --zstd -xf peach_robot-v1.0.0.tar.zst
cd peach_robot-v1.0.0
python3 scripts/package_release.py --check ../peach_robot-v1.0.0.tar.zst
bash scripts/deployment/deploy.sh --system --verify --jobs 2
```

`--system` 需要 root/sudo。脚本安装依赖、构建 45 个 ROS 包和两套网页资源，`--verify` 只做使能全关的 mock 检查，结束后停栈。追加 `--web-e2e` 做 HTTP 浏览器检查，追加 `--grasp` 显式执行工具关闭的 mock 单果干跑。常驻 mock 按[根入口](../../README.md)启动。

宿主无 ROS 或 sudo 时，可按[部署说明](../../scripts/deployment/README.md)创建独立 Ubuntu Base 环境。安装阶段联网，运行验证阶段仅有独立回环网络；环境与宿主共享内核。

## 包内容

- 全部 45 个 ROS 包的源码、配置、现行文档和第三方许可；只读驱动内容保持不变。
- `src/peach/peach_scene_perception/model/` 的 best.pt、FastSAM-s.pt、mobile_sam.pt；保留运行必需的机器人、相机 SDK 和浏览器 vendor 资产。
- `runs/data/delivery_simulation_20261106/` 的 bag、metadata、8 帧 npz 及来源记录，固定使用 index 0 的交付示例。
- 部署/验证/发布脚本、35 项 Python 固定版本、两个 npm lockfile、VERSION、CHANGELOG 和 RELEASE_MANIFEST.json。
- 精选的 2026-11-07 验收 JSON、日志与截图；原始路径仅作追溯，发布包复查记录另附在交付目录。

构建/安装产物、venv、node_modules、SDK dist、下载缓存、Git/IDE/AI 会话、重复上游源码缓存和历史运行包不随稳定包交付。IVG 可选模型与 Gazebo YCB meshes 按原有 fetch 脚本恢复，不属于 Peach 稳定范围；Peach 权重始终保留。没有 Git 索引时保留现有源码资产，不据缺失索引删除文件。

## 已知限制

此前只读 AUBO 驱动有 7 项 lint 检查失败、70 个 cppcheck 用例跳过，本版不将部署通过视为全仓 lint 通过。旧 IVG dashboard 的 ros_web_link/共享 JS 缺口仍在，未启动 dashboard。真实机械臂、相机/串口、SetIO、真实剪切、原生 WS 网页抓取、Orin 与 10×30×1800 长测未验收；Gazebo 保持暂停。L6 mock 不作为现场采摘成功证明。

## 维护与复现打包

```bash
python3 scripts/package_release.py --dry-run --output ../releases/v1.0.0
python3 scripts/package_release.py --output ../releases/v1.0.0
```

稳定发布目录不可覆盖；后续变更先更新 VERSION、CHANGELOG 和对应发布说明，再输出到新目录。打包使用显式白名单、完整文件哈希和目录清单，保留 CMake 需要的空目录，不要求 Git；记录、源码和模型的包含范围由脚本检查。完整清理记录保留于本机 `runs/releases/v1.0.0/`。
